========================================
三角洲口琴助手 使用说明
（Delta Harmonica Helper · 个人使用版）
========================================

一、这是什么
------------
一个 Windows 上的口琴自动弹奏辅助工具。启动后，你只需要按回车键（Enter），
程序就会自动帮你按下对应的口琴按键、并自动按住调音用的鼠标键：

  · 按住 Enter  → 弹奏当前音符（按下对应键盘键 + 按住需要的鼠标调音键）
  · 松开 Enter  → 释放，并自动跳到下一个音符

升调 / 降调 / 半音会自动按住鼠标的 右键 / 左键 / 中键，而且同一个调音区间里
不会反复松开再按下（无抖动）。


二、怎么启动
------------
  · 双击桌面快捷方式「Delta Harmonica Helper」
  · 或直接运行：dist\DeltaHarmonicaHelper\DeltaHarmonicaHelper.exe

启动后弹出图形界面（标题「Delta Harmonica Helper」），不会出现黑色命令行窗口。


三、界面说明
------------
  Status         当前状态：Idle（就绪）/ Playing（演奏中）/ Paused / Stopped /
                 Ready / Opened / Error
  Current Note   当前要弹的音符；弹完后显示 -
  Score          琴谱编辑区（多行文本框），在这里写琴谱
  按钮           Start 开始 · Pause 暂停 · Resume 继续 · Stop 停止 ·
                 Reset 回到开头 · Open 打开琴谱 · Save 保存


四、琴谱怎么写
--------------
【基本音符】
    1 2 3 4 5 6 7 1'
    其中 1' 是高音 1（数字 1 后面跟一个单引号）。

【调音区间】用方括号 [ ] 圈出一段要变调的音符：
    [↑ 1 2 3]   升调（整个区间按住鼠标右键）
    [↓ 4 5]     降调（整个区间按住鼠标左键）
    [~ 6 7]     半音（整个区间按住鼠标中键）
  区间结束会自动回到普通（normal）。

【完整示例】
    1 2 [↑ 3 4 5] 6 [~ 7 1'] [↓ 2]

【其他规则】
  · 分隔符：空格、Tab、换行都可以
  · 注释：# 到行尾是注释，不会被演奏
  · ASCII 写法：+ 等价于 ↑，- 等价于 ↓
  · 调音符号必须写在方括号里（如 [↑ 1 2]），不能单独写 ↑ 1


五、音符 → 键盘按键对照
-----------------------
    1    →  Z
    2    →  X
    3    →  C
    4    →  V
    5    →  B
    6    →  N
    7    →  M
    1'   →  逗号  ,


六、调音 → 鼠标按键对照
-----------------------
    普通      （无）        不按
    升调      ↑ 或 +        右键
    降调      ↓ 或 -        左键
    半音      ~             中键


七、操作流程
------------
  1. 在 Score 区写好琴谱（或点 Open 载入一个 .txt 琴谱）
  2. 点 Start（进入 Playing，从第一个音符开始）
  3. 按住 Enter 弹当前音符，松开 Enter 释放并进到下一个音符，反复弹完整首
  4. 弹完后 Current Note 显示 -
  5. 想再弹一遍：点 Reset（或按 R）回到开头，再按 Enter 即可


八、快捷键
----------
  Enter   演奏（按住=弹，松开=释放并前进）。仅 Start 后生效
  Esc     紧急停止（立即释放所有输入，位置不变，可再 Start 继续）
  R       重置到琴谱开头（index 回到 0）

  注意：程序会全局拦截 Enter 键，演奏期间你在别的窗口按 Enter 也会被程序接管。
  演奏前请确保焦点在游戏窗口里（音符按键和鼠标会发到当前前台窗口）。
  不演奏时点 Stop 或按 Esc 即可停止接管。


九、打开 / 保存琴谱
------------------
  Open          打开一个 .txt 琴谱文件（UTF-8 编码）。若正在演奏会先安全停止
                再加载，不会自动恢复演奏
  Save / Save As  把当前 Score 区内容保存成 .txt
  打开空文件 → Score 为空；打开含非法音符的琴谱 → 只在点 Start 时提示 Error，
  不会崩溃。


十、常见问题
------------
  Q：按 Enter 没反应？
  A：先点 Start 进入 Playing，Enter 才会触发演奏。

  Q：弹奏时音符发到了错误窗口？
  A：程序把音符按键/鼠标发到当前前台窗口。请先把焦点切到游戏窗口再按 Enter。

  Q：想暂停 / 继续 / 停止？
  A：点 Pause（暂停）、Resume（继续）、Stop（停止并释放输入）。

  Q：怎么退出程序？
  A：点窗口右上角的 ✕ 关闭即可（会先释放所有输入再退出）。

  Q：min_hold_ms 是什么？
  A：config.json 里的 min_hold_ms = 50，表示每个音符最短保持 50 毫秒，避免
     极短误触导致音符没弹出来。一般不需要改。
